# Instructions for downloading Minecraft worlds

There are two versions of each Minecraft world included here in this repo. One is compatible with Java, and the other is compatible with Bedrock. Check which version of Minecraft you have before downloading any files. If you are using Miencraft Education Edition, download the Bedrock worlds.

## Java world download instructions
1. Download the Newfoundland Minecraft world as a zip file archive
2. Unzip the archive to a temporary location
3. Type “%appdata%” into the windows search bar and press enter
4. Open the “.minecraft” folder
5. Open the “saves” folder
6. Move the unzipped archive to this ‘saves’ folder
7. Open Minecraft, and you should see the Newfoundland world in your lists of worlds, ready to play!

## Bedrock world download instructions
1. Download the Map: Download the .mcworld file
2. Open the File: Double-click the .mcworld file
3. Import: Minecraft will open and automatically import the world
