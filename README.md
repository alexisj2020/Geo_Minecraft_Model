# READ ME!
This repository contains the code and relevant maps/images used for building geologic maps/models in Minecraft.
This is part of an earth sciences outreach program designed to create outreach materials which will hopefully inspire more interest in geosciences amongst younger people.
The goal of my project is to build learning tools related to geology in Minecraft. These include a geologic map of Newfoundland in Minecraft, and code which builds gravity and magnetics maps from Minecraft worlds.
Much of the initial work involves using other programs such as WorldPainter and QGIS. The work I'm doing in these programs is explained in text files located in the additional info folder (coming soon).
