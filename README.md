# READ ME!
This repository contains the code and relevant maps/images used for building geologic maps/models in Minecraft.
This is part of an earth sciences outreach program (MUNGO) designed to create outreach materials which will hopefully inspire more interest in geosciences amongst younger people.\
The goal of this project is to build learning tools related to geology in Minecraft. These include a geologic map of Newfoundland in Minecraft, and code which builds gravity and magnetics maps from Minecraft worlds.\
All codes used to develop these materials are included in this repository. The **maps** folder includes any necessary maps which are used for the development of these materials. The **How To** folder contains files with instructions on how these materials were built. Feel free to use these codes and instructions to make gravity and magnetics maps of your own Minecraft worlds, or even to make geologic maps of other parts of the world.
