To use code to build Minecraft worlds, you need to have some connection between Minecraft and your codes. For this project, I have used the HTTPS interface designed for the Generative Design in Minecraft Competition (GDMC). The details and installation instructuions are found at https://github.com/Niels-NTG/gdmc_http_interface/blob/master/README.md. You will need to have a working version of Minecraft Java on your computer. Everything else listed in the installation tutorial is free and publicly available.

The main functions used for building Minecraft worlds through code include reading and placing blocks. These functions are part of the Generative Design Python Client (GDPC) Python Library. A tutorial on how to install GDPC and how to use these functions can be found at https://gdpc.readthedocs.io/en/stable/#contents.

These tutorials taught me everything I know about setting up and writing ccode to edit Minecraft worlds.
