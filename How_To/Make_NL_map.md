# Making a geologic map of Newfoundland in Minecraft
Building the Newfoundland map involves multiple steps, some involving other programs that you will need if you want to try building your own maps. These programs include WorldPainter, which is used to generate Minecraft worlds from elevation maps, and QGIS, which is used to make elevation and geologic maps from available data. Both of these applications are free to use.

The first step in building this map is finding the necessary data. .dbf files are obtained from freely available resources online. The geologic data is acquired from the GeoAtlas NL website, and the elevation data is acquired from the Department of Forestry, Agriculture, and Lands GeoHub of NL website. These data are imported in QGIS to make maps of these data. Both maps are saved as PNGs, making sure that the lateral extent and resolution of both maps is the exact same.

## Making the base map
The base Minecraft world is made in WorldPainter. To do this, open WorldPainter and import the elevation map by going  to File -> Import new World -> From height map. Here we decide what the size of the map will be. For the NL map,  we set the size to 20% of the original size of the image, which comes out to 1153 x 852 blocks in Minecraft. The height mapping values should also be changed to make sure the elevation isn't overly exaggerated. Under the "To Minecraft" section, we set "Low mapping" to 0, "Water level" to 0, and "High mapping" to 40 (this may take some iteration to decide what looks best). Then, we click OK to generate the world. We can click View -> Show 3D view to see what the world looks like. If the elevation looks too exaggerated or too flat, try importing the map again and change the mapping values. To generate the Minecraft world, go to File -> Export -> Export as new Minecraft map. Then, we make a few final adjustments. Here, select the desired world mode (survival or creative) and whether to allow cheats and structures. Also, set the centre of the world. We want the corner of the map to be at (0,0), so set the centre of the world as the centre of the map (half the coordinates set when importing the height map). Also, go to the surface tab and select the desired border type (I recommend void or water, I chose void for the NL map). Now we save this map as a Minecraft world, making sure to save it in the appropriate saves folder of the Minecraft app. If you would like more info on how to use WorldPainter, check out this tutorial I found which taught me everything I know https://www.youtube.com/watch?v=E1cPiqghlys&list=LL&index=19.

## Incorporating the geology
Now we want to set up a legend for the geology, where we map each of the rock types in the geologic map to a Minecraft block type. You can go through the geologic data in QGIS, and look at the RGB values and rock type for each element in the data. Minecraft only has so many block types, so you'll need to simplify the geology a bit. For the NL map, my legend consists of a spreadsheet with the rock type and RGB values for each element on the geologic data. In another column, I list the block type chosen to represent that rock type. I group together elements that have the same rock type. So if there are multiple elements with rock type listed as felsic intrusive rock, I would represent all of those with granite in Minecraft. Some elements are simplified. For example, multiple elements are listed as having multiple rock types, such as clastic and chemical sedimentary rock. For more vague rock descriptions such as these, I represent them with the stone block in Minecraft. 

Now we move on to using the codes included in this repo. We can write code to edit Minecraft worlds. Make sure you have the right setup by going to Code_to_Minecraft.md first. 

The first thing we've done is add water to the ocean of the map. You can skip this step if the area you're modelling doesn't have any ocean. To do this, open the Minecraft world made made in WorldPainter, and run the "add_water.py" file. This code detects all areas where the height of the ground in the Minecraft world is at 0 elevation, and then replaces the top block with air, and the block below with water. This puts an "ocean" around the island.

Now we can add the geology into the Minecraft world. This is done by running the "1_1_Mil_Geology.py" file with the Minecraft world open, which places Minecraft blocks according to the map and legend. This code has a few steps to it. The first is importing the geologic map made in QGIS and converting it to a numpy array with RGB values, with the same dimensions as the Minecraft world. Next, the numpy array is edited to remove any RGB values that don't exist in the original map. These RGB values appear due to the resizing of the map, causing some pixels/elements to merge. To remmove these values, a list of RGB values of the original map are checked. If any elements in the array do not match up to one of the RGB values in this list, its value is replaced by an adjacent element which has an apropriate RGB value. Next, the Minecraft blocks are placed according to the legend and RGB values of the numpy array. For example, if intrusive felsic rocks are represented by granite in Minecraft, and represented by RGB value 100,25,30 in the geologic map/numpy array, this code will place granite in the Minecraft world at all coordinates where this RGB value appears in the numpy array. The geologic map is the same throughout the vertical direction, because we only have surface data available, so we don't know how the geology changes in the subsurface. After this code finishes running, the NL map has the bedrock geology added in. 

## Adding in more details
We can add more details to the map by incorporating data from mineral occurrence maps. We obtain these from the GeoAtlas NL website. On this website, we can look at occurrences for each mineral separately. We obtain data for gold, iron, coal, copper, and beryl (because these minerals occur in NL and there are Minecraft blocks of these ore types). We can import these data into QGIS to make mineral occurrence maps for each of these minerals. We design the maps to show coloured squares wherever mineral occurrences are reported. The size of these squares can be changed depending on how large we want the mineral occurences to be in the Minecraft world. We then save each of these maps as PNGs. The python file "ore_maps.py" converts these maps into numpy arrays with the same dimensions as the Minecraft world and saves these arrays as text files. These files are then used in "ore_deposits.py" to place these mineral deposits in the Minecraft world according to their location in the array. This is a similar process as was done for the geologic map. The vertical level of the ore bodies is randomly decided, where for each lateral location where a mineral deposit occurs, five ore blocks are placed vertically in Minecraft at that location, with their vertical coordinates somewhere between 0 and 10 blocks below the surface height. They are placed shallowly so that players will be able to easily find these ores. Unfortunately, the connection to Minecraft is weak, and will get overloaded if we ask it to do too much at once. So, the script "ore_placing.sh" is written to run "ore_deposits.py" for one line in the Minecraft world at a time. By only doing one line at a time, the server does not get overloaded and will not shut down. To place the ore bodies in the Minecraft world, we run "ore_placing.sh" in a terminal window with the NL map world open. 

Lastly, we can also add some roads to the Minecraft world to help with navigation for players. A road map for NL is available on the GeoAtlas website. This data is loaded into QGIS, and filtered to make a map of only the main roads on the island. This map is saved as a PNG which shows only the road locations in black lines. The file "add_roads_nl.py" converts this map to a numpy array, and places bricks along the surface of the Minecraft world where the roads are located in the map.

Now we have our map of Newfoundland containing the elevation, bedrock geology, mineral deposits, and the main roads! If you have elevation and geologic data, you can make a similar map of anywhere in the world! The NL map contains additional information, but this was all done manually in the world itself, and required no code.
